## 🌟 Visão Geral
O **ConeCTEA** é uma solução tecnológica mobile criada para apoiar a comunidade vinculada à **Família TEA Bauru**. Mais do que um aplicativo, é uma ponte de conexão que organiza a identidade digital dos membros, simplifica processos internos e garante que o acolhimento chegue de forma ágil e segura a quem precisa.

> [!IMPORTANT]
> **Aviso Legal:** A carteirinha emitida pelo ConeCTEA é um documento de identificação **interno** para uso exclusivo nos projetos e parcerias da Família TEA Bauru. Ela **não substitui a CIPTEA oficial** emitida pelos órgãos governamentais.

## 🚀 Principais Funcionalidades

*   🔐 **Cadastro e Login Seguro:** Acesso autenticado via e-mail e senha.
*   👤 **Perfil do Usuário:** Governança completa de dados com proteção de campos críticos.
*   👨‍👩‍👧 **Fluxo de Membros:** Cadastro direto de dependentes e titulares com validação real de CPF.
*   📊 **Acompanhamento de Solicitações:** Visibilidade total do status das carteirinhas em tempo real.
*   💎 **Carteirinha Digital Modular:** Identidade visual premium "Night Blue" com frente, verso e QR Code de validação.
*   📱 **Tela Cheia Adaptativa:** Visualização da carteirinha com layout defensivo para os modos Retrato e Paisagem.
*   📢 **Mural e Notificações:** Avisos importantes e novidades da associação.
*   🛡️ **Área Administrativa:** Painel para gestão de solicitações e auditoria interna.

---

## 💎 Diferenciais do Projeto

*   **Android-First:** Desenvolvido com foco inicial no ecossistema Android, com validações progressivas em dispositivos reais.
*   **Arquitetura Modular:** Estrutura organizada por funcionalidades (features), facilitando a manutenção e escalabilidade.
*   **Acessibilidade Visual:** Paleta "Night Blue" desenhada para reduzir sobrecarga sensorial.
*   **UX Inclusiva:** Interfaces que seguem princípios de clareza visual e Comunicação Alternativa (CAA).
*   **Segurança Robusta:** Proteção de dados via Supabase Row Level Security (RLS).

## 🛤️ Roadmap Comercial

### ✅ Concluído
- Design System Night Blue Premium consolidado.
- Fluxo de **Requests** (Solicitações) totalmente reestruturado e com validação de CPF.
- **CardsView** modularizada com estados dinâmicos (vazio, pendente, erro).
- **Carteirinha Digital** modularizada (Frente, Verso, Fundo, Movimento).
- **FullScreenCardPage** com layout adaptativo e proteções contra overflow.

### 🚧 Em Andamento
- Revisão completa dos fluxos de Autenticação (Login/Registro).
- Continuação da reestruturação e revisão das próximas features.
- Padronização visual de componentes globais, botões e inputs.

### 📅 Próximas Melhorias
- Responsividade global Android para diferentes tamanhos de tela e aparelhos comuns no Brasil.
- Módulo de Benefícios e Parcerias.
- Notificações push ativas para alertas de renovação.
- Variante clara do tema (Light Mode).
- Futura exportação de carteirinha para PDF (em estudo).

### 🔮 Futuro
- Integração com o projeto **"Fada do Dente"**.
- Funcionalidades offline para identificação básica.
